# Подключение Supabase

Подключение сделано напрямую из браузера через Supabase JS SDK, как в проекте `CB`. В `script.js` указаны URL проекта и publishable key; SDK загружается через CDN на HTML-страницах.

1. В проекте `umhrceixwdakatnozccz` откройте **SQL Editor**.
2. Вставьте содержимое [`supabase/schema.sql`](supabase/schema.sql) и нажмите **Run**.
3. Откройте Mini App в Telegram. При первом входе будет создан профиль с 100 звёздами и пустым списком NFT. При следующих входах приложение загрузит сохранённый профиль и баланс.

Через редактор профиля в Supabase сохраняются ник, имя, описание, телефон и день рождения. Баланс и NFT читаются из строки `telegram_profiles`.

Для этого временного прямого режима SQL открывает таблицу роли `anon`. Это соответствует текущему варианту `CB`, но позволяет клиенту обращаться к данным напрямую. Не храните здесь чувствительные данные; ограничения доступа нужно добавить отдельно перед запуском для реальных пользователей.

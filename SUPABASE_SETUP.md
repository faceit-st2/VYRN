# Подключение Supabase

Подключение сделано напрямую из браузера через Supabase JS SDK, как в проекте `CB`. В `script.js` указаны URL проекта и publishable key; SDK загружается через CDN на HTML-страницах.

1. В проекте `umhrceixwdakatnozccz` откройте **SQL Editor**.
2. Вставьте содержимое [`supabase/schema.sql`](supabase/schema.sql) и нажмите **Run**.
3. Вставьте содержимое [`supabase/marketplace.sql`](supabase/marketplace.sql) и нажмите **Run**. Этот SQL создаёт таблицу объявлений и атомарные операции продажи, отмены и покупки. Если маркетплейс уже настроен, выполните обновлённый файл повторно, чтобы включить удержание 5% комиссии при покупке; комиссия округляется вверх до целой звезды.
4. Вставьте содержимое [`supabase/chat.sql`](supabase/chat.sql) и нажмите **Run**. Скрипт создаст личные диалоги и сообщения, а также добавит обе таблицы в публикацию Supabase Realtime.
5. Откройте Mini App в Telegram. При первом входе будет создан профиль с 100 звёздами и пустым списком NFT. При следующих входах приложение загрузит сохранённый профиль и баланс.

Для проверки без Telegram откройте `index.html` в Chrome. Браузер создаст локальный аккаунт с постоянным ID и синхронизирует его с `telegram_profiles`; профиль, баланс, коллекция и операции рынка будут использовать эту запись. Ищите локальный профиль в админ-панели по имени `Локальный аккаунт` или по ID из `localStorage` (`vyrn.local.user.v1`). Локальный ID хранится в данных этого браузера и не является авторизацией.

Через редактор профиля в Supabase сохраняются ник, имя, описание, телефон и день рождения. Баланс и NFT читаются из строки `telegram_profiles`. В профиле во время получения коллекции отображается «Загрузка NFT…». Кнопка «ПРОДАТЬ» в модалке позволяет указать цену и выставить NFT на рынок. Лоты находятся в `nft_listings`; покупка одной транзакцией списывает звёзды у покупателя, начисляет их продавцу и передаёт NFT. Отменённый лот возвращает NFT продавцу.

Для этого временного прямого режима SQL открывает таблицы роли `anon`. Клиент пока не использует подтверждённую Supabase Auth-сессию, поэтому данные чатов доступны через публичный API и не подходят для приватной переписки реальных пользователей. Перед запуском для пользователей необходимо подключить проверенную авторизацию и ограничить RLS по участникам диалога.

Админ-панель находится в `admin.html`. Откройте её через локальный веб-сервер или по адресу размещённого сайта `/admin.html`. Сейчас вход администратора не ограничен: любой, у кого есть адрес страницы, может искать пользователей, менять баланс и выдавать NFT. Не публикуйте страницу до добавления проверки администратора.
